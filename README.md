# Employee Data Analysis System

## 📌 Project Overview

The Employee Data Analysis System is a Python and Pandas project that analyzes employee data to generate meaningful business insights. The project includes data cleaning, exploration, analysis, and visualization using Matplotlib.

---

##  Features

- Load employee data from a CSV file
- Clean missing values
- Perform exploratory data analysis (EDA)
- Analyze employee salaries
- Department-wise employee analysis
- City-wise employee analysis
- Identify top-paid employees
- Generate business insights
- Create visualizations using Matplotlib
- Export cleaned data

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

---

## 📂 Dataset

The dataset contains the following columns:

- EmployeeID
- Name
- Department
- Age
- Salary
- Experience
- City

---

## 📊 Business Questions Solved

- Total number of employees
- Employees in each department
- Department with the highest average salary
- Highest salary
- Lowest salary
- Average salary
- Employees earning more than ₹60,000
- Employees older than 30
- Employees with more than 5 years of experience
- Employees from the IT department
- Employees from Pune
- Top 5 highest-paid employees
- Employee with the highest salary

---

## 📈 Visualizations

- Department-wise Employee Count
- Department-wise Average Salary
- Salary Distribution (Histogram)
- Employees by City
- Top 5 Highest Paid Employees

---

## 💡 Key Business Insights

- Pune has the highest number of employees.
- Most employees earn between ₹45,000 and ₹60,000.
- The IT department has one of the highest average salaries.
- Only a few employees earn more than ₹80,000.
- The salary distribution is concentrated in the lower to middle salary range.
