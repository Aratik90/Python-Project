# 🎓 Student Management System

![Python](https://img.shields.io/badge/Python-3.x-blue)
![JSON](https://img.shields.io/badge/Storage-JSON-green)
![Status](https://img.shields.io/badge/Project-Completed-brightgreen)
![License](https://img.shields.io/badge/License-MIT-orange)

A console-based Student Management System developed using Python. This project allows users to manage student records with complete CRUD (Create, Read, Update, Delete) operations and stores data permanently using a JSON file.

---

## 📌 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student by ID
- 🔍 Search Student by Name
- ✏️ Update Student Details
- 🗑️ Delete Student
- 🚫 Prevent Duplicate Student IDs
- ✅ Input Validation
- 💾 Automatic Save to JSON File
- 📂 Automatic Load from JSON File
- 👨‍🎓 Display Total Number of Students
- 📊 Calculate Average Marks
- 🏆 Find the Topper Student
- 🔢 Sort Students by Name
- 🔢 Sort Students by Marks
